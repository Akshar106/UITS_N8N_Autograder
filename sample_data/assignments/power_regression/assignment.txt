# Module Two — Assignment 2
## Electricity Consumption: Preprocessing and Regression

**Total: 20 points**

### Description

In this scenario, you are provided data on the electricity consumption in a
town. The data is organized into 7 columns:

- Date Time
- Temperature
- Humidity
- Wind Speed
- General diffuse flows
- Diffuse flows
- Power consumption

### Task

Download the data: **M2 Electricity_Consumption-1.csv**

### Steps

Conduct data preprocessing. This includes:

1. Execute data preprocessing — including verification and handling of repeated
   rows, addressing missing values, converting categorical variables to
   numerical variables, and applying feature scaling and feature selection if
   necessary.
2. Analyze and visualize the multicollinearity in the dataset (find correlations
   between the variables).
3. Implement **simple linear regression** to predict the power consumption of
   the town. Provide results, the accuracy score of the prediction, and a
   visualization.
4. Implement **polynomial linear regression**. Provide results, the accuracy
   score of the prediction, and a visualization.
5. Implement **multiple linear regression**. Provide results, the accuracy score
   of the prediction, and a visualization.
   1. Compare and explain the results of the regression models in your own
      words.

### Criteria for Success

The attached rubric indicates how the assignment will be graded.

**Note:** For simple linear regression, identify the two "best" features that
exhibit a linear relationship with the target variable. Apply simple linear
regression separately to each feature and compare the scores obtained.

**Note:** Data preprocessing is mandatory for all assignments. Each assignment
should involve the application of all necessary methods for data preprocessing.
Neglecting this step will result in a reduction of marks.
