Q1. TotalCharges has some blanks so I convert it to numeric and fill the gaps. The categorical columns get one-hot encoded. The numeric columns get scaled.

Q2.
    import pandas as pd
    from sklearn.compose import ColumnTransformer
    from sklearn.pipeline import Pipeline
    from sklearn.impute import SimpleImputer
    from sklearn.preprocessing import StandardScaler, OneHotEncoder
    from sklearn.model_selection import train_test_split

    df = pd.read_csv("telco_churn.csv")
    df["TotalCharges"] = pd.to_numeric(df["TotalCharges"], errors="coerce")

    y = (df["Churn"] == "Yes").astype(int)
    X = df.drop(columns=["Churn", "customerID"])

    num = ["tenure", "MonthlyCharges", "TotalCharges", "SeniorCitizen"]
    cat = ["Contract", "PaymentMethod", "InternetService"]

    prep = ColumnTransformer([
        ("num", Pipeline([("imp", SimpleImputer(strategy="median")),
                          ("sc", StandardScaler())]), num),
        ("cat", OneHotEncoder(handle_unknown="ignore"), cat),
    ])

    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.2, stratify=y, random_state=0)

The transformer is fitted inside the pipeline so only training data is used.

Q3.
    X["avg_spend"] = X["TotalCharges"] / X["tenure"].replace(0, 1)
    X["m2m"] = (X["Contract"] == "Month-to-month").astype(int)

These two should be useful features for predicting churn.

Q4.
    from sklearn.ensemble import RandomForestClassifier
    from sklearn.model_selection import GridSearchCV, StratifiedKFold

    pipe = Pipeline([("prep", prep), ("clf", RandomForestClassifier(random_state=0))])
    grid = {"clf__n_estimators": [200, 400],
            "clf__max_depth": [6, 10, None],
            "clf__min_samples_leaf": [1, 5]}
    search = GridSearchCV(pipe, grid,
                          cv=StratifiedKFold(5, shuffle=True, random_state=0),
                          scoring="f1", n_jobs=-1)
    search.fit(X_train, y_train)

I used a random forest and searched over the tree parameters with 5-fold stratified CV.

Q5.
    from sklearn.metrics import classification_report, roc_auc_score, average_precision_score
    best = search.best_estimator_
    proba = best.predict_proba(X_test)[:, 1]
    print(classification_report(y_test, best.predict(X_test)))
    print(roc_auc_score(y_test, proba), average_precision_score(y_test, proba))

Accuracy is not a good metric for this dataset because the classes are imbalanced. Precision, recall and F1 are better. I also print ROC-AUC and PR-AUC.

Q6. The scaler is fitted before the split, which is leakage. You should split first and then fit the scaler on the training set only.
